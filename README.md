# Streamerr Live

Professional audio broadcasting software for streaming to Icecast and Shoutcast servers.

## Download

Download the latest version from the [Releases](https://github.com/unmutedtech/streamerr-cast-windows/releases) page.

- **StreamerrBroadcast-win-Setup.exe** - Windows installer (recommended)
- **StreamerrBroadcast-win-Portable.zip** - Portable version (no installation required)

## Features

- **Multi-stream broadcasting** - Stream to multiple servers simultaneously
- **Audio codecs** - MP3 and AAC support with configurable bitrates
- **Real-time audio mixing** - Mix microphone and system audio
- **Audio processing** - Built-in compressor, limiter, and noise gate
- **StreamerrPanel integration** - Quick Connect with your StreamerrPanel token
- **Live metadata** - Update artist and title in real-time
- **Listener monitoring** - Track listener counts across all streams
- **Auto-updates** - Automatic update notifications and installation

## System Requirements

- Windows 10 version 1903 or later
- .NET 8.0 (included in installer)

## Quick Start

1. Download and run the installer
2. Add a stream via **Configure** or use **Quick Connect** for StreamerrPanel
3. Select your audio devices in **Preferences**
4. Click **Go Live** to start broadcasting
